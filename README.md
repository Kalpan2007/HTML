# UI Clone Collection (HTML & CSS Only)
A collection of user interface (UI) clones of popular platforms and applications built using only HTML and CSS.

## Overview
This repository contains clones of various web applications and platforms, including:
- YouTube
- Spotify
- Calculator
- Netflix
- Chess
- Sudoku
- Cricket App
- Ludo
- Kids World
- Superwar

These projects are built purely with HTML and CSS, focusing on frontend design and layout.


## Usage
Open the HTML files in your browser to view and interact with the UI clones.

## Technologies Used
- HTML
- CSS
